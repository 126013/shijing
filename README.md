> AI 伴读古诗，带孩子把诗词读成沉浸短片。

## 一、项目简介

诗境是一款面向低龄孩子的古诗词学习应用。围绕「读得懂、记得住、愿意看」，把一首古诗拆成可逐幕步入的沉浸场景：按诗人籍贯与朝代漫游山河，检索喜欢的诗词，借助朗读、白话译文与意境配图理解诗意，并可一键生成由逐幕画面、诗句字幕与意境配乐合成的知识短片，辅助记忆与诵读。

### 一句话简介（20 字以内）

AI 伴读古诗，带孩子把诗词读成沉浸短片。

## 二、核心功能

| 模块 | 说明 | 入口 |
| --- | --- | --- |
| 诗人地图 | 诗人行迹示意图：按朝代筛选诗人、查看生平与代表作，支持自动巡游。节点为示意排布，非地理坐标。 | `/` |
| 古典书库 | 关键词检索，按朝代、题材、作者筛选；可随机入一境。 | `/library` |
| 沉浸阅读 | 全诗按诗句分幕呈现，每幕一幅程序化意境画面；附白话译文，支持逐幕切换与整首朗读。 | `/read/[id]` |
| 朗读 | 优先使用豆包（火山方舟）TTS；未配置密钥时自动降级为浏览器 Web Speech，并在界面标注实际音源。 | 阅读页 |
| 生成短片 | 阅读页一键合成：逐幕画面 + 诗句字幕 + 程序生成配乐（WebAudio 五声音阶），保存到影片馆供回看与下载。 | 阅读页 → `/video` |
| 影片馆 | 本地（IndexedDB）影片列表，支持回看、下载、删除。 | `/video` |

## 三、技术栈与第三方工具库

- **框架**：Next.js 15（App Router）+ React 19 + TypeScript，无其他运行时依赖
- **样式**：手写 CSS（`app/globals.css`），深夜青绿底 + 暖金强调色，楷体标题
- **意境画面**：程序化生成（`lib/scene/art.ts` 定义画面，SVG 用于页面、Canvas 用于短片），无外部图片依赖，离线可用
- **朗读**：豆包 TTS（可选，服务端持有密钥）/ 浏览器 Web Speech 降级
- **短片合成**：Canvas 逐帧绘制 + WebAudio 配乐 + MediaRecorder（`lib/video/recorder.ts`），全程浏览器本地完成
- **存储**：影片存 IndexedDB（`lib/storage/videos.ts`），朗读设置存 localStorage
- **测试**：Vitest（数据层与纯函数）
- **诗词数据**：仓库内置 15 首带逐句译文与分幕提示的精选集；可选接入 chinese-poetry（MIT）全量数据接口

### 数据源说明

| 场景 | 行为 |
| --- | --- |
| 未配置 `POETRY_API_BASE` | 使用仓库内置精选集（15 首，含译文与分幕），全功能可用 |
| 配置了 `POETRY_API_BASE` 且接口可用 | 列表 / 详情 / 统计走线上全量数据（如 344,315 首），无译文的诗自动按两句一幕拆分并明确标注 |
| 配置了但接口不可用 | 自动回到精选集，并在界面上显示降级提示，不静默伪装 |

## 四、本地运行

```bash
# 1. 安装依赖（Node.js ≥ 20）
npm install

# 2. （可选）配置环境变量
cp .env.example .env.local
#   POETRY_API_BASE   接入线上全量诗词接口（不配置则用内置精选集）
#   DOUBAO_TTS_*      接入豆包语音合成（不配置则用浏览器朗读）

# 3. 启动开发服务器
npm run dev
# 打开 http://localhost:3000

# 4. 测试 / 生产构建
npm test
npm run build && npm start
```

**零配置即可完整体验**：不配置任何环境变量时，「首页 → 书库 → 沉浸阅读 → 浏览器朗读 → 生成短片 → 影片馆回看/下载/删除」全流程可用。

### 目录结构

```
app/                  页面与 API 路由（App Router）
  api/poems/…         列表 / 详情 / 随机 / 统计 / 诗人 / TTS
  library/  read/[id]/  video/
components/           页面组件（home / library / reader / video-gallery / scene）
data/                 精选诗词与诗人行迹数据
lib/
  data/               类型定义与查询层（本地精选集 + 可选远程数据源）
  scene/              程序化意境画面（SVG / Canvas 共用一份画面描述）
  speech/             朗读控制（豆包 TTS 优先，Web Speech 降级）
  video/              短片合成（Canvas + WebAudio + MediaRecorder）
  storage/            影片 IndexedDB 存储
tests/                Vitest 单元测试
```

### 浏览器支持说明（短片）

- 短片合成依赖 `MediaRecorder` + `canvas.captureStream`，桌面版 Chrome / Edge 体验最佳
- 导出格式为 WebM（部分浏览器为 MP4）；文件只存在本机浏览器中，清除站点数据会删除影片
- 浏览器朗读（Web Speech）的声音无法被 MediaRecorder 捕获，因此未配置服务端 TTS 时，导出的短片为「字幕配乐版」，界面会如实标注

## 六、当前局限与迭代规划

**当前版本局限**

- 仓库内精选集为 15 首；接入线上接口可获得全量数据，但译文与分幕提示目前只为精选集撰写
- 诗人行迹图为示意排布，不是地理地图；诗人资料仍在补充
- 短片以逐幕画面 + 字幕 + 配乐合成，画面之间为淡入淡出切换；浏览器朗读的声音无法进入导出影片

**后续迭代方向**

- 短片从静态切镜升级为 AI 动态分镜视频，加入镜头运动与场景过渡
- 扩充诗人籍贯、生平与代表作资料
- 面向低龄儿童补充注音、背诵测评、闯关打卡等学习环节
